# Winter 0.123.0

## Images in code sessions

- Paste or drag an image into a code session's message box, or press ctrl+v in the terminal app, and it
  appears as `[Image #1]`. Pasting an image file's path works too.
- Large images, such as Retina screenshots, are shrunk when you attach them, so they always fit.
- Your message shows `[Image #n]`. The model receives the saved image and looks at it.
- If the selected model can't read images, Winter says so as soon as you attach one: "The selected
  model doesn't support images".
- Chat and dispatch sessions are unchanged for now.

## Files in replies open in the side panel

- When the model names a file in its reply, the path is a link. Click it and the file opens in the
  right-hand panel.
- An image path also shows a small preview. Click it to see the full image in the panel, fitted to
  size; double-click for actual size.

## Models see images from tools

- When a model reads an image file, it now sees the picture itself on every provider. Before, it got
  the image's raw data as text.
- Images returned by MCP tools and notebook plots reach the model as images too.
- Long sessions with many screenshots stay within each provider's image limits instead of failing.
- A model that can't read images gets a short note instead of unreadable data.

This release runs on Winter agent SDK 0.0.36 and runtime SDK 0.0.15.
