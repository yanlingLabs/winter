# Winter 0.122.1

## Fixes

- `winter mcp permissions` works again. In 0.121.0 and 0.122.0 it stopped with an error before
  showing or changing anything.

## Terminal

- Drag to select text in the conversation or the input box, then press ctrl+c to copy it.
- Click a file path in the conversation to open the file.
- Large pastes no longer make typing lag.
- Brighter look: white input borders and status line, and a blue-grey background behind your own
  messages.

## Models

- Claude Sonnet 5.5 is available with an Anthropic API key or a Console sign-in. Like Opus 5.5, it
  can change effort and pick up new tools partway through a conversation without losing the prompt
  cache.

This release runs on Winter agent SDK 0.0.35 and runtime SDK 0.0.15.
