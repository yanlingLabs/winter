# Winter 0.115.1

## Winter's own jobs run on your model

Chat titles, the purge, dreaming and the command reviewer only ran when your default model was a
Codex or OpenAI one. With any other default they were quietly switched off.

- These jobs now run on any model except Claude ones. By default they use your default model's
  provider, or a Codex or OpenAI sign-in if you have one; you can choose each one in
  **Settings › Roles**.
- When one of them cannot run, **Roles › Notes** says why — no key for its provider, or no model
  chosen — instead of saying nothing.
- The command reviewer never stops: if its chosen model cannot run, it keeps reviewing on another
  and says so.
- Settings changes now apply without a restart whatever your default model is.

## Fixes

- The **Remove** buttons in **Settings › Providers** open their confirmation again.
