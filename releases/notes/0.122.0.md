# Winter 0.122.0

## Models and providers

- **Nearly three hundred more models.** DeepInfra's full chat lineup, recent OpenAI models (GPT-5.3
  Codex, GPT-5.2 and GPT-5.2 Pro, GPT-5.1, GPT-5 and GPT-5 Pro), GPT-6 Sol and Luna on Azure OpenAI,
  Kimi K3 on eleven hosts, Qwen 3.8 Omni Flash, Step 5 preview, Doubao Seed 2.1, Palmyra X6, and the
  latest frontier models on OpenRouter.
- **New providers:** OVHcloud AI Endpoints, Crusoe and Tinfoil. Snowflake Cortex and Cloudflare
  Workers AI work with your own account's address, the way Azure does.
- **More complete details.** Context size, output limits, reasoning support, tool support and prices
  are filled in for hundreds of models from each provider's own documentation, and almost twice as
  many models now show a price.
- **Retired models are marked**, including Perplexity Sonar and Groq's Llama 3.3 70B. Winter's Llama
  picks now point at hosts that still serve them.
- **Providers whose service has shut down are no longer offered:** Yi, Pioneer, Modal and
  Hyperbolic. A key you stored for one of them stays in your Keychain, but Winter no longer lists it.

This release runs on Winter agent SDK 0.0.34 and runtime SDK 0.0.15.
