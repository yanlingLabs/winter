# Winter 0.120.0

## Sign in to MCP servers

- **MCP servers that need a sign-in now work.** Add a server such as GitHub or Cloudflare,
  then sign in from Library → MCP on the Mac, or with `winter mcp login <name>` in the terminal.
  Winter opens your browser, you approve it there, and the server's tools appear.
- **Servers that register themselves, servers that use Winter's published client, and servers
  that need your own OAuth app** are all supported. For your own app, store its client secret with
  `winter mcp set-secret <name>`, or with `--from-clipboard` from a shell that can't prompt. The
  secret is sent only to the sign-in server you confirmed.
- **Until you sign in, a server's tools stay hidden** and the model is told the server needs a
  sign-in, instead of failing mid-task.
- **Signing in or out takes effect in sessions that are already open.** The server reconnects on
  its own; nothing restarts.
- **Winter keeps you signed in.** A sign-in is refreshed only when it has expired, and only by Winter
  itself. Sign out with `winter mcp logout <name>`.
- `winter mcp list` shows whether each server is signed in.

## Choose what each connector may do

- **Every connector action can be set to Always allow, Always ask or Always deny.** Set them per
  action or for a whole server in Library → MCP, or with `winter mcp permissions <server>`. A change
  applies to the next call in every session, with nothing to restart.
- **Chat and Dispatch can now use connectors.** An action that needs your approval shows a card in
  the conversation (Dispatch cards reach the iPhone too). Chat still never asks about anything else.
- **Actions the server marks as read-only run without asking** until you choose otherwise.
  Everything else asks.
- **Always deny holds everywhere**, including in Bypass mode and over approvals you saved earlier.

## No more Keychain prompts

- **Sessions no longer read the Keychain themselves.** Winter hands each session the one credential
  it needs, so macOS stops asking you to allow access for every rebuilt or updated runtime.
- **The Mac app reads its pairing tokens without asking.** Winter re-creates them once after this
  update so the app is trusted to read them.
- `winter doctor` checks for leftover credentials without opening them, so it never prompts either.

## Fixes

- **Adding, showing or removing an MCP server for your user** (`winter mcp add -s user`) works
  again while Winter is running. It used to be refused.

This release runs on Winter agent SDK 0.0.32 and runtime SDK 0.0.15.
