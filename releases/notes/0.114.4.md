# Winter 0.114.4

## Reasoning effort follows the model, never the other way round

A model's catalog row says which reasoning efforts it accepts, and many rows accept none at all.
Winter used to push a stored effort onto whatever model a session ran, and the runtime then
refused the turn ("declares no reasoning effort vocabulary"). The assistant conversation hit this
as soon as its model changed to one without an effort vocabulary.

- A fixed or default effort (the assistant session's, for example) is now mapped onto the model's
  own vocabulary, or simply left out so the provider's default applies.
- Setting an effort on a session whose model accepts none is refused with a clear message, and
  the pickers only offer what the model's row declares. `winter model --effort` checks the same.
