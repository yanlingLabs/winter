# Winter 0.114.3

## A retry is never a bare spinner

When a provider answers with something worth retrying (a rate limit, a server error), the runtime
retries with growing pauses, up to ten times. Until now you saw only the spinner for up to ninety
seconds. The retry attempts now reach you as they happen: the terminal's spinner and the Mac's turn
chip read "Provider busy (HTTP 429), retrying 3 of 10, next in 8 s", and clear the moment the turn
moves on. These are live progress lines only; nothing is written into the conversation, and a
retried request that then succeeds leaves no trace. The frame comes straight from the runtime,
which uses the same retry frame as the Claude Agent SDK, so both runtimes report it identically.

## The daemon keeps a log

The daemon now writes everything it logs to `~/.winter/logs/daemon.log` (8 MB, one previous file
kept), whether the app launched it or you ran `winter daemon run`. `winter doctor` prints the path.
Until now the app discarded the daemon's output entirely.
