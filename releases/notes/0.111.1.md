Winter 0.111.1 — patch

- Fixed: on installs signed in with Codex (OpenAI OAuth), Claude models could not be selected for a session — `session.create` and `session.setModel` refused every Claude model as "unknown model" before the runtime decision, so the official Claude leg was unreachable even with an Anthropic API key stored. Catalog models and their aliases are now accepted alongside the internal provider's own list.
