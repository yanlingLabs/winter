# Winter 0.121.0

## New models

- **Space Bunny**, an anonymous preview model, is available free on OpenCode Zen
  (`opencode/space-bunny-free`) and on OpenRouter (`openrouter/stealth/space-bunny-alpha`). Who makes
  it has not been announced. OpenCode says its provider keeps no data; OpenRouter's terms for
  stealth models allow prompts to be collected for training.
- **About seventy more models can run sessions**: NVIDIA-hosted models, and Claude-compatible
  endpoints from Tencent, Baidu Qianfan, Z.AI, Wafer and AgentRouter, wherever the provider
  documents tool support. Models with no documented tool support stay hidden.

## Connectors

- **A connector that asks you to open a link now shows a card** with the site it goes to, instead of
  being refused. Choose Open link or Decline. The link is never saved, and the terminal can answer
  it too.
- **Rename a connector** with `winter mcp rename`; it keeps the connector's permissions. `winter mcp remove`
  now also clears the connector's permissions when nothing else uses that name. Both list any saved
  allow or deny rules that still mention the old name, so you can edit them.
- **Permissions follow the exact connector** that runs an action. A subagent's own connector that
  shares a name with one of yours never inherits your Always allow.
- A message sent while a connector is reconnecting now waits briefly for it instead of missing its
  tools, and a connector that withdraws a request removes its card.
- Two plugins that add a tool with the same name no longer clash.

## Keychain

- **Only Winter itself can read your saved keys and sign-ins.** On first launch Winter saves each
  one again so that access older Winter builds were given is dropped. Nothing is lost if this is
  interrupted, and nothing prompts.
- If another Winter process is still updating credentials, Winter waits for it and says so in the
  menu bar.
- Workflows refuse to run unless they are sandboxed away from the Keychain.

## Fixes

- `winter-dev` sign-in hints name the command you actually ran.

This release runs on Winter agent SDK 0.0.33 and runtime SDK 0.0.15.
