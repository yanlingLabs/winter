# Winter 0.114.1

## A Codex usage limit now tells you, immediately

When your ChatGPT plan's Codex usage window is exhausted, the backend answers "usage limit
reached" with a reset time. Winter treated that as a momentary rate limit and retried it ten
times with growing pauses, showing only a spinner for about ninety seconds. Most people gave up
before the real reason appeared, and pressing Esc left the turn marked "Interrupted" with no
explanation.

The limit is now reported as a final error within a couple of seconds, naming the plan and the
reset time: "usage limit reached (plan: plus), resets in 48 min". Switch the session to another
provider's model in the picker, or wait for the reset.

## `/model` in the terminal now switches the session you are in

`/model <tag>` in the TUI used to rewrite only the default for new sessions while the running
session kept its model, and it said "takes effect next turn", which was wrong. It now switches
the attached session the same way the Mac app does, and updates the default too. A switch that
would lose part of the conversation (moving away from a model with private reasoning) is
refused with an explanation; `/model <tag> --confirm` switches anyway.

Agent SDK 0.0.14 carries the usage-limit fix; nothing else changed in the runtime.
