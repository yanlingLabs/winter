# Winter 0.120.1

## Fixes

- **Winter 0.120.0 could not start its background service**, so the menu-bar orb showed
  "Disconnected" right after the update. macOS stopped the service the first time it touched the
  Keychain. This update gives it the permission it needs, and every release now checks for it
  before shipping. Nothing in your Keychain was changed.

This release runs on Winter agent SDK 0.0.32 and runtime SDK 0.0.15.
