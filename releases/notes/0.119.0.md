# Winter 0.119.0

## Faster, cheaper turns

- **Plan mode keeps the prompt cache.** Entering or leaving plan mode used to throw away the whole
  cache on OpenAI models (and most of it elsewhere). The plan-mode instructions now arrive as a
  message at the end of the conversation, so the start of the prompt never changes.
- **Reasoning token counts** are now reported for OpenAI, Codex, xAI and other reasoning models
  that report them.

## Subagents and MCP

- **A subagent waits for its own MCP servers** (briefly, as the main session does), so their tools
  are there on its first turn.
- **A subagent's MCP server with the same name as yours no longer replaces yours.** It gets its own
  name, and your rules and hooks for the server still apply to it.
- **Interrupts and model switches answer right away** while MCP servers are still connecting.
- **Forked agents can run tools they load themselves** on Claude Opus 5.5, Claude Sonnet 5 and
  DeepSeek Flash, and on OpenAI models with tool search.
- **MCP servers loaded from the discovery cache pick up tool changes** once they connect.
- **Adding an MCP server keeps its protocol-version setting.** `winter mcp add` now keeps
  `versionNegotiation`, and `auto` negotiation is safe on stdio servers: one that exits on the
  probe is restarted once in legacy mode.

## Hooks

- **Async hooks** (`async: true`) run in the background without holding up the tool call. Their
  messages reach the model at the next safe point. They can never allow or deny a call, and
  security hooks always stay synchronous.
- **Hooks know which MCP server a tool came from** (`mcp_server_name`, `mcp_tool_name`).
- **A hook that times out is cancelled**, and the shell-command reviewer stops its model call.

## Model pickers

- **Models that can't use tools are hidden from session pickers** (Mac, terminal and iPhone). A
  session already set to one gets a clear message on its next turn instead of breaking.
- **The shell-command safety reviewer works on Claude Opus 5.5 and Fable 5.1.**
- **Fewer wrong "this switch loses context" prompts.**
- A chat-completions provider with no endpoint configured now says so, instead of quietly
  falling back to OpenAI's address.

## iPhone

- **Hook notices and continuity warnings appear on the iPhone** once you update the iOS app.

## Security

- **Writes to protected folders are checked through symbolic and hard links**, after a failed
  `cd`, and in many more command spellings. When a command is too complex to judge, Winter asks
  instead of guessing.
- **A saved approval is re-checked against where a link points** when the command runs.
- **A repository can't raise your permission mode or change your settings behind your back.** A
  `.winter/settings.local.json` that the repository ships (tracked in git, linked or in a
  submodule) is treated like the project's own settings. Repository settings can't set the effort
  level or thinking options either.
- **The output style comes from your own settings only.** A project can no longer pick your
  output style or redefine one of yours, and its styles always keep the coding instructions.
  If you set a style in a project's settings, set it in Winter's settings instead.

## Plugins

- **Plugins with the same name from different marketplaces** no longer collide.
- **Keyboard shortcuts saved for a plugin carry over** after this update.
- **A revoked plugin consent stays revoked**, and a stray folder in the plugins directory no
  longer triggers a migration.
- **The consent sheet says when a plugin's background process won't start** (it runs only for
  plugins installed for you, not for a project).

## Everything else

- **Worktrees:** agents, output styles, workflows and memory listings now show what a session in a
  worktree actually loads.
- **Chat and dispatch clean up background processes** left behind when a session stops
  unexpectedly.
- **Subagent notices and model switches stay with the subagent** instead of touching the main
  conversation.

This release runs on Winter agent SDK 0.0.28 and runtime SDK 0.0.15.
